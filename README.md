# Moulding Production Analytics System

Industrial AI + Data Analytics Dashboard for Injection Moulding Manufacturing.

## Project Overview

This project is a complete manufacturing analytics and production planning system developed using:

* Python
* Streamlit
* Pandas
* Plotly
* Machine Learning

The dashboard helps analyse:

* Production
* Raw Material Consumption
* Manufacturing Cost
* Rejection Loss
* Machine Capacity
* OEE
* Forecasting
* Productivity Improvement
* Incentive Profit Analysis

---

# Features

## 1. Production Summary

* Shift-wise production analysis
* Monthly production tracking
* Total output monitoring

## 2. RM Analytics

* Raw material consumption analysis
* RM cost calculation
* Material-wise usage tracking

## 3. Machine Capacity Planning

* Machine utilisation analysis
* Shift requirement calculation
* Available vs required capacity

## 4. Cost Trend Analysis

* Manufacturing cost analytics
* RM cost + moulding cost analysis
* Part-wise manufacturing cost

## 5. Rejection Loss Analytics

* Rejection percentage analysis
* Quality efficiency monitoring
* Rejection loss cost calculation

## 6. Power Consumption Analytics

* Machine power usage estimation
* Heater and motor running analysis
* Energy cost monitoring

## 7. Production Forecasting (AI)

* Monthly production forecasting
* Future production prediction
* Trend analysis using Machine Learning

## 8. Incentive Profit Analysis

* Production increase simulation
* Operator incentive impact analysis
* Manufacturing cost reduction analysis

## 9. OEE Dashboard

* Availability %
* Performance %
* Quality %
* Overall Equipment Effectiveness

# Installation

## Clone Repository

```bash
git clone https://github.com/P4pal2004/moulding-production-analytics.git
```

## Move into project folder

```bash
cd moulding-production-analytics
```

## Install requirements

```bash
pip install -r requirements.txt
```

## Run Streamlit App

```bash
streamlit run app.py
```
